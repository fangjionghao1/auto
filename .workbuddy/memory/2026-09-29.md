## 读懂 E:\auto 三脚本流水线（用户要求熟读分析）

项目是一条「稿件生产流水线」，三个脚本各司其职：

1. `watch_src.py` — 订单入库：用 `gh api` 轮询 GitHub 仓库 `src/` 目录的新 txt 订单（部门/采编/订单时间/类别/作者/题目），下载到本地 `src/`；格式不全 → 改名 `.faild.txt`（原文即此拼写）；与 goal.md 历史及 `1.txt` 基准查重 → 改名 `.duplicate.txt`；合格则向 `src/goal.md` 台账追加行。稿件ID = `文件名-MMDD(-序号)`，上传日期取该文件最近一次 commit 的 committer date。状态存 `.git/watch-src-state.json`（文件名→sha），`--once` 单次，默认 60s 循环。
2. `generate_src.py` — 脚手架：读 goal.md 中「进度 ≠ 完成」的行，按 `gen-src-repo/src.md` 模板的 `## §0 参数区` YAML 块替换 文章题目/预投期刊/目标语言（type 以"EI会议"开头 → 中英双稿，否则中文稿），生成 `gen/artifacts/{稿件ID}/{状态}/{标题}/src.md` 并复制 `speek.md`。
3. `finalize_artifacts.py` — 收尾打包：遍历 `gen/artifacts/*/*/*` 中含 `论文.md` 的目录：写 `仿真/env.txt`（MATLAB R2025b、seed 42）；用 python-docx 给每个 docx 加居中页脚「第 X 页」（PAGE 域）；把 `仿真/` 打成 `仿真打包.zip`；统计论文参考文献前的中文字数并打印。

注意点：finalize 不会创建 `仿真/` 目录（不存在会报 FileNotFoundError）；watch 的 state 按文件名去重，同名重传会被跳过；goal.md 必备列：稿件ID/auth/type/标题/状态/进度/src（或产物路径）。
