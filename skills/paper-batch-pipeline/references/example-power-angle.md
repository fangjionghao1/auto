# 可直接运行的案例：功角预测先导未覆盖失稳事件

## 使用

已安装本skill后，可直接提出：

```text
使用 $paper-batch-pipeline，在一个新的隔离目录运行自带案例，展示提示词回显、Python先导审查、重设计记录及goal.md进度更新。
```

也可从命令行运行（Python 3.10+，无第三方依赖）：

```text
python "<SKILL_DIR>/scripts/demo_case.py" --output "<新的隔离目录>"
```

必须选不存在的目录；脚本拒绝覆盖已有目录。自带`assets/example-workspace`含一组src/speek、示例台账、演练审稿规则和可运行的先导脚本，运行后才生成数据及状态。

## 完整演练过程

1. 扫描唯一项目：`gen/artifacts/1-0001/V1/功角稳定预测方法演练`。
2. 合成总提示＋src＋speek＋审稿规则，保存`final_prompt.md`并完整回显。
3. 以该目录为工作目录运行Python先导，用小扰动正阻尼线性振子的解析解，计算60个合成工况。时间窗40秒、采样间隔0.02秒、随机种子20260929。
4. 检查有限窗口内是否达到2π极滑代理阈值，保存CSV逐工况结果、JSON统计和运行日志。
5. 依据实际结果输出`重设计记录.md`、状态JSON，先预览、再仅修改示例台账“进度”。

## 为何不能放行

这组参数与正阻尼线性模型已排除了题目需要识别的非线性失步现象。更多同类样本或更复杂预测网络无法修复这一设计缺口。“未达到代理阈值”不能扩展为实际场站稳定证明，也不能把全预测为稳定的平凡准确率写成研究成果。

该案例的数字明确为演练合成值，不具有现场参数或工程结论的含义。低阶模型也可以有效服务有限的研究问题；此处失败的具体原因是模型未保留当前分类任务需要的机制。

## 保存的重设计方向

重新明确物理对象、预测时点和可获得信息；引入有依据的必要非线性、电网耦合及故障清除机制；冻结合理工况范围、标签和未判定处理；加入物理裕度等强基线；预先确定有效收益及约束；按物理族划分独立测试。算法没有有效贡献时继续重设计，不能事后挑指标或挑样本。

这些是**下一轮计划，尚无验证结果**。通过新一轮科学门禁后，才进入正式MATLAB执行、FIG/PNG及原始资产交付、论文和审稿流程。

## 输出入口

运行目录内：

- `demo-result.json`：本次实际计算与状态摘要。
- `scan.json`：项目、身份、输入与规则哈希。
- `update-preview.json` / `update-applied.json`：台账更新预览及实际写入记录。
- `src/goal.md`：示例进度。
- 项目内`final_prompt.md`、`先导/`、`重设计记录.md`、`.paper-pipeline/status.json`：过程证据。
