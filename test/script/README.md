# 论文闭环验证规则 · VERIFICATION SPEC v2.0

> 项目：论文编写  
> 定位：本项目交付门禁的唯一权威说明；目标刊或会议的最新正式要求仍是投稿格式的最高依据。  
> 验证责任人：FJH（论文编写项目总负责人／守门人）  
> 修订日期：2026-09-29

## 1. 适用范围与判定原则

适用于 EI 会议、中文普刊、中文科技核心、SCI 收录期刊的研究论文；“指定普刊”直接采用该刊配置，“只写不发”采用最接近的论文类型做内容核验。综述、短文、案例、通信等稿型必须另建配置，不能套用研究论文的篇幅值。

1. **先定目标，再验格式。** 建立“目标配置卡”：刊名／会议名、稿型、官网指南与模板 URL、查看日期、页数或字数及计数口径、图表和文献要求、盲审／语言／声明／返修文件要求。编辑部决定信中的返修要求优先于一般投稿指南。若与本规则的规划值冲突，以目标方要求为准，并记下冲突与采用依据；若与用户明确给定的项目要求无法同时满足，则标“待决策”，由用户调整要求或更换目标，不得自行放宽后放行。
2. **区分三类数值。** “目标硬限”违反后不能标记投稿就绪；“项目要求”是本项目交付门禁；“规划值”只触发核对和说明，不能单凭偏离推断拒稿。EI 是检索类别、SCI 是索引类别，二者没有统一篇幅标准。
3. **可复现且留痕。** 每次报告保存规则版本及 SHA-256、稿件和关键数据／图表文件 SHA-256、核验时间、目标配置卡、发现问题的页码／段落／图表号／原句、证据路径、处置与复审结果。无证据不得标“已核”。
4. **学术事实优先。** 不编造数据、图表、文献、DOI 或审稿意见；仿真、实测、公开数据、理论推算必须如实区分。物理方程、量纲、边界条件、统计方法和推理链须自洽。外部查重、伦理审批及编辑决定由相应机构完成；本项目核查稿件中应有的来源、许可和声明。
5. **缺省目标的状态。** 尚未选定期刊／会议，可以交付明确标记的“研究稿”；不得标记“投稿就绪”。刊名已给出但官网要求尚未核实，先补齐目标配置卡。
6. **实验有效性判定**。如果实验设计最终得出结论无研究成果/方案对现有问题无有效贡献，判定实验为无效，重新设计实验和题目相关的实验和文稿。

## 2. 四类稿件的篇幅、图表和文献配置

下表中“默认”均指研究论文的**项目内规划**，只有 EI 行明确注明的项目要求按交付门禁执行。字数与页数不可直接换算；最终按目标方模板和统计口径复核。主文图表按独立编号的图或表计数，子图 a／b／c 合计为一幅图，补充材料另计；不能为凑件数拆分、重复或虚构结果。

| 类别               | 篇幅配置                                                                       | 主文图表配置                                                              | 文献配置                                                           | 判定属性                                          |
| ---------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------- |
| **EI 会议正式全文**    | **目标会议页限为硬限**；未定会议先按 IEEE 双栏约 6 页、含图表与文献规划。中文对照稿正文约 4000–4500 汉字，仅作项目写作目标。 | **项目要求恰好 5 幅**，默认图 3＋表 2；换成其他图表配比需说明论证用途。                           | **项目要求恰好 10 条**，按正文首次出现顺序编号，均落在指定 **2021—2026 年份窗**，每条有已核 DOI。 | 页数、模板等按会议；5 幅／10 条／年份窗／DOI 为本项目要求，发生硬限冲突则待决策。 |
| **中文普刊**         | 未定刊先按中文整稿约 **5000–8000 字**规划；具体刊物可能以含图表字数或页数计。                             | 建议 **3–6 幅必要图表**，初稿可按图 3＋表 2 规划；无必要图表时不强凑。                          | 建议 **至少 10 条**可核文献，时效性与格式按目标刊。                                 | 规划值，不能当普刊通用录用线。                               |
| **中文科技核心**       | 依据技能的 10 篇样本：全文约 **6000–6500 中文字符**、正文净字数约 **4000–8000**。                  | 样本归纳建议 **图 3–8、表 2–6**；关键是图表足以证明方法与结果、全部在正文被引用。无表时核查是否确实无合适的参数或结果表。 | 样本建议 **12–18 条**、近 5 年文献比例约 **≥90%**，保留必要奠基文献。                 | 全部是样本指导值；具体科技核心期刊优先，偏离应说明研究设计原因。              |
| **SCI 收录期刊研究论文** | 未定刊先按英文正文约 **4000–6000 词**规划；目标刊及稿型的词数／页数与排除项为硬限。                          | 先按 **4–8 个**有论证作用的图表规划；具体刊可能有上限，也可能不限。                              | 可先按 **30–60 条**规划；新近与经典文献比例、引文制和 DOI 政策按目标刊。                   | 全部是未定目标时的规划值；不能当 SCI 统一规定。                    |

**计数记录：**报告须分别列明正文净字数或词数、整稿计数、模板排版页数、主文图数、主文表数、补充图表数、参考文献条数及使用的统计工具。若目标刊有自己的“含摘要／不含方法／图表折算字数”等口径，报告同时保留目标口径。中文正文净字数指引言至结论的文本，不含标题、摘要、图表内字、图题表题和参考文献；这是项目规划口径，不替代刊方计数。

**EI 年份口径：**2021—2026 含首尾共六个自然年份，因此称“项目指定年份窗”，不要称其为严格的五个自然年。此窗口是本次项目配置；跨年或更换目标会议时重新确认。10 条的 DOI 需能解析，元数据须与题名、作者和出版年匹配；不得为满足数量编造或错配 DOI。确有不可替代且无 DOI 的标准／数据集时，保留真实来源于研究底稿，记录与项目要求的冲突；在用户明确调整本稿要求或改用符合要求的引用方案前，不得标“投稿就绪”或“项目要求已通过”，也不得伪填 DOI。其他三类有 DOI 则核对，无 DOI 按目标刊要求提供可靠书目信息或 URL。

**科技核心近期文献口径：**未有目标刊定义时，“近 5 年”按核验年及前四个自然年计，2026 年即 2022—2026；以所引用版本的正式出版年为准，在线先发年份不同须备注。该比例是技能样本建议值，不是普刊或 SCI 的通用门槛。

**科技核心适用性：**技能中的图表、文献、公式、对照实验和统计次数来自 10 篇录用论文，不是所有科技核心期刊的统一硬规定。多模块方法宜有消融；需要比较优劣的结论须有公平对照；纯理论、案例或资料受限研究按其论证方式评估并写明“不适用”理由。不得为了满足数量而制造实验。

## 3. 一次完整验证：先快检，再核证据

### V0　目标与版本，自动优先

核实目标配置卡、稿型、目标方指南及模板、稿件／图表／数据版本哈希。对指定刊会核实刊会官网与征稿信息，不能把“会议声明拟送数据库”写成“已被 EI 检索”。快速扫描页数或字数、图表数、图表与公式编号、文内引用、文献数量与 DOI 字符串、缺文件和明显修改残留。自动扫描只产生候选问题，人工复核后定级。

### V1　文字、结构与排版

核对题目—摘要—关键词—正文一致；摘要包含目的、方法、可追溯的主要结果和结论。全文术语、缩写首现、符号、单位、数值精度、中英对应、标题层级和公式编号统一。按目标模板检查标题、摘要、关键词、声明、图题表题位置、双盲匿名、图片格式和最终 PDF 的可读性；目标没有要求时不强加中图分类号、双语题名或固定摘要字数。输出有问题的原句、位置和改法。

### V2　数据、图表与科学事实，人工必查

为每项关键结论建立“**主张 → 方法／脚本或原始记录 → 汇总计算 → 图表 → 正文／摘要／结论**”证据链。核对同一指标的对象、工况、样本量、时间窗、基准、单位、取整规则与数值；复算比率、合计和核心统计量。检查图表依首次引用编号、题注自明、坐标与单位齐全、图例无遮挡、分辨率可读、误差和显著性表述有依据。核查模型假设、量纲与物理约束、对照公平性、重复性和结论边界；不得把最优工况冒充总体表现、把仿真称为实测、把相关说成因果。关键结果无法溯源或复算时不能通过。

### V3　主题与论证闭环

建立精简的“标题承诺／引言问题 → 方法 → 结果证据 → 结论回应”矩阵。每个核心问题须有对应证据，题目限定词须在研究对象和工况中落实；创新点须与真实相关文献比较，不能只改名称。对该研究确有必要的基线、消融、灵敏度／不确定性或局限性讨论要齐备。研究设计不需要的项目标“不适用＋理由”，不补虚假实验。

### V4　文献、合规与审稿视角

逐条核对文献真实存在、作者／题名／年／卷页或文章号／DOI 相符，引用点与文献结论相关，文内引文与文后条目互相对应；顺序编码制只在目标刊或项目 EI 配置要求时强制。检查撤稿状态、必要的数据／代码可得性、伦理与利益冲突及作者贡献声明是否按目标方要求提供。模拟审稿只输出“主要优点、必须修复的问题、可选改进、证据位置、目标匹配风险”；评分可按需附加，**不得把 70／85 分直接写成可发表或录用预测**。

## 4. 问题分级与放行

| 等级 | 判定 | 处置 |
| --- | --- | --- |
| **Blocker** | 伪造或无法解释的关键数据／图表／引文、抄袭或重复发表嫌疑、物理或数学核心错误、结论与证据相反、关键主张无来源、目标方明令禁止事项 | 停止放行；保留证据，修复后复审。涉嫌学术不端交守门人处理，不由脚本作终局裁定。 |
| **Major** | 可修复但影响可信度、复现、核心可读性或目标硬限的错误，如关键参数缺失、图表与正文不符、格式页限超标、重要返修意见未回应 | 交付前必须修复并复审。 |
| **Minor** | 不改变研究判断的文字、标点、局部体例问题 | 集中修复；若保留，记录原因及责任人。 |
| **Info** | 编辑偏好、可选优化或不适用项 | 记录即可。 |

“未核实”不是“通过”。关键数据来源、核心推导、目标硬限或 EI 项目要求未核实，视其影响列为 Blocker 或 Major。若单纯偏离普刊／科技核心／SCI 的规划区间，但目标方无相应硬限，只记 Info 或给出简短解释。

**研究稿可交付**须满足：V1–V4 已审、无未解决 Blocker 或 Major、关键主张证据链完整、图表和引文可追溯、报告与文件哈希已归档，并由 FJH 签署。**投稿就绪**还须有目标配置卡、按该刊会模板和稿型完成所有硬限及文件检查，作者确认需其承担的署名、伦理和声明。内部审查通过仅说明本项目交付门禁通过，不保证外审结果或数据库收录。

## 5. 返修闭环与快速复审

每轮先保存稿件差异、编辑／审稿意见、答复表和新哈希。逐条答复每条意见：原意见、处理决定、修改位置、证据；不能采纳时说明可核实的理由。标红、Word 修订痕迹、清洁稿、单独图文件等**按目标刊规定**，不可统一强制一种格式。

| 本轮变化 | 必须复验 |
| --- | --- |
| 仅错字、措辞、版面 | V1 的改动处；全稿快速扫编号、引文、图表链接；复查最终渲染页。 |
| 摘要、标题、引言、结论或引用解释 | 改动处的 V1／V3；所有受影响的主张链、V2 数值与文献引用。 |
| 图、表、公式、参考文献增删或重排 | V2／V4 的改动项及所有交叉引用；全稿编号、数量、页数快检。 |
| 仅稿件中的关键量化值订正，原始数据与计算链未变且已证明 | 独立重算受影响指标，核同一指标在摘要、正文、图表和结论中的全部出现位置；无法证明计算链未变则 V2 全量重算。 |
| 原始数据、代码、模型、样本、指标定义或统计方法变化 | **V2 全量独立重算**，再核摘要—正文—图表—结论及 V3／V4 相关结论。 |
| 目标刊、稿型、模板或决定信变化 | V0 目标配置卡全量更新，相关格式与交付文件重检。 |

所有修订轮次都重跑**成本低的全稿机器快检**；原始数据、代码、模型、样本、指标定义或统计方法变化时强制 V2 全量独立重算。稿件中单项录入纠错按已证明未变的计算链重算受影响指标与全部出现位置。人工复审聚焦改动点及其影响面，不能因快检通过而跳过关键证据链。第三轮仍有重大问题时升级 FJH 决定补证据、改投／改稿型或继续修订；轮次本身不是科学质量判据。

## 6. 最小验证报告与脚本边界

每个稿件版本只保留一份汇总报告，建议放在 test/script/reports/。报告至少含：

| 字段 | 内容 |
| --- | --- |
| 标识 | 稿件 ID、题名、稿型、目标刊会、指南 URL 与查看日期 |
| 版本 | 规则版本及 SHA-256；中英稿、最终 PDF、关键数据、图表文件的 SHA-256；验证时间 |
| 计数 | 字数／词数口径、模板页数、图数、表数、文献数、年份窗、DOI 核验数 |
| 结论 | 研究稿可交付／投稿就绪／待修订；Blocker、Major、Minor 数量 |
| 证据 | 问题 ID、V 项、页码／段落／图表号、双方原值或原句、来源文件、修复动作、复验结果 |
| 返修 | 审稿意见逐条答复、变更位置、触发的复验范围、未采纳理由 |
| 签署 | FJH 签署、日期及尚存 Minor／Info 清单 |

现有 test/script/check_gate_evidence.py 可只读收集文件结构、哈希、DOCX 公式／图片／表格计数等证据；它**不能**替代 V1 语义审校、V2 科学复算、V3 主题判断或 V4 文献核实。test/script/check_v2_project8.py 只适用于特定项目，不可当通用 V2。自动检查失败或不适用必须在报告中明记，不能把“脚本运行完”当作放行。

## 7. 规则依据与更新

- **科技核心：**本机 kehe-paper-review 技能的 SKILL.md 与 references/规范细则.md；后者由 10 篇录用稿归纳，数值仅作经验指引。
- **EI：**[Elsevier Compendex](https://www.elsevier.com/promotions/compendex)说明 EI 是工程文献检索数据库；[IEEE 会议稿型说明](https://conferences.ieeeauthorcenter.ieee.org/become-an-ieee-conference-author/types-of-ieee-conference-papers/)将正式全文通常描述为 6–8 页，并要求查具体会议；项目的 5 幅图表／10 条文献不是 IEEE 或 EI 的通用规定。
- **普刊：**[《西北水电》](https://sbxx.cbpt.cnki.net/EditorE3N/PromptPageInfo.aspx?c=1&t=v)要求含图表 5000–8000 字；[《江西化工》](https://prov.cbpt.cnki.net/EditorAN/PromptPageInfo.aspx?c=1&t=v)对纯文字稿和图表较多稿设不同下限；[《北京测绘》](https://bjch.cbpt.cnki.net/EditorE2N/PromptPageInfo.aspx?c=1&t=v)建议 4000–6000 字、含图表不超过 5 页。由此不能推出普刊统一限额。
- **SCI：**[Nature Article](https://www.nature.com/nature/for-authors/formatting-guide)的典型正文与图表量、[ASME Research Paper](https://www.asme.org/publications-submissions/journals/information-for-authors/journal-guidelines/journal-submission-types)的 8000–12000 词与 5–8 个图表，以及[PLOS ONE](https://journals.plos.org/plosone/s/submission-guidelines)不限制字数和图数的规则，说明必须逐刊逐稿型建配置。
- **返修：**[PLOS ONE](https://journals.plos.org/plosone/s/revising-your-manuscript)要求逐条回复、标记稿和清洁稿；中文刊的[《河南水利与南水北调》](https://hnbd.cbpt.cnki.net/EditorE2N/PromptPageInfo.aspx?c=1&t=v)要求标红且不要修订格式，说明返修文件形式应随目标方要求。
- **中文引文格式：**目标刊格式优先；无目标格式时以现行 [GB/T 7714—2025](https://std.samr.gov.cn/gb/search/gbDetailedCNF?id=4507EFE13D37CB6AE06397BE0A0A601F) 为默认参考。若目标刊指南仍写旧版，按该刊要求并在配置卡记录版本。
