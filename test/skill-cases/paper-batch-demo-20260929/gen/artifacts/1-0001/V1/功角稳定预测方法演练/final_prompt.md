## 四、实验有效性红线：不闭环就重设计

先用Python或MATLAB做数量级、必要条件和小规模先导，形成 `先导核验.md`。至少检查：

| 检查 | 无效/不足的典型证据 | 必须采取的动作 |
| --- | --- | --- |
| 现象与类别覆盖 | 稳定预测只有稳定类；只比较平凡场景；声称级联却未覆盖所需级数 | 定位合理参数域、缺失机制或标签定义，不把未判定强行改正类；重设覆盖方案 |
| 约束是否有辨别作用 | 热限远高于可能负荷；爬坡/安全约束从不活跃，却声称靠它改进 | 数量级分析、真实边界/压力工况及消融，验证贡献机制 |
| 模型是否过度理想化 | 删除决定性耦合、噪声、饱和或动态；参数只在虚构区间成立 | 补关键机制和有依据参数，核物理/数学可实现性；不是盲目增加模型复杂度 |
| 方法是否有效解决问题 | 关键目标无改善/不达标；被同信息简单基线支配且无预先定义的成本或可行性收益 | 分析方法结构、信息、目标函数与问题不匹配，重设计方法及实验 |
| 证据是否能支撑主张 | 只展示最佳种子；统计误差覆盖全部效果；测试泄漏；用同一总负荷节点细分证明真实大规模泛化 | 重建隔离划分、必要对照和不确定性检验，收集与主张相称的证据 |
