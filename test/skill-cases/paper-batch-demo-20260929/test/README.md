# 演练审稿规则

只用于隔离演练，不替代生产工作区的审稿规则。

1. 标题承诺稳定/失稳预测时，先导必须说明两类事件能否在合理场景中出现。未出现所需现象不能判实验有效。
2. 若模型省略关键机制、实验过分理想化、方法没有有效解决原问题，实验无效，必须保存根因分析并重设计，不可交付。
3. 最终MATLAB资产包含真实运行的.m、.mat、.csv、成对.fig/.png、环境和日志及可复现.zip。Python先导不等于MATLAB交付。
4. 全部科学门禁、独立复算、稿件和资产核验通过后，并由示例守门人签署才能完成；未取得签署保留待签署。
5. 最多3轮完整重设计，仍失败则记录阻断，不伪造成功结果。本演练只执行第一轮先导和重设计计划，不运行后续主实验。
