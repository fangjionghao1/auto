## 计算依据

来源为 src.md 声明的合成设计数据 pilot.csv。20 个唯一 case，各含一条预测；全部纳入，无缺失、非有限值或负负荷/预测值。字段单位 kW；实际负荷范围 100–195 kW。原始输入与脚本哈希见 先导指标.json 和审稿报告.md。

MAE_m = Σ_i |prediction_im − actual_i| / 20。

| 项目 | 精确复算值 |
| --- | ---: |
| 基线绝对误差之和 | 20 kW |
| 新方法绝对误差之和 | 80 kW |
| 基线按工况等权 MAE | 1 kW |
| 新方法按工况等权 MAE | 4 kW |
| 原先合格线：0.9 × 基线 MAE | 0.9 kW |
| 新方法 / 基线 MAE | 4 |
| 新方法 − 基线 MAE | +3 kW |
| 超出合格线 | 3.1 kW |
| 相对改善率 1 − 4/1 | −300%（误差增加 300%） |
| 新方法改善 / 持平 / 更差的工况数 | 0 / 0 / 20 |

每个工况基线残差为 ±1 kW，新方法残差为同符号的 ±4 kW，两者有符号误差均值均为 0。平均偏差相消不能证明预测准确。观察到的关系 e_proposed = 4e_baseline 只描述这份合成表；缺少算法、预测生成脚本和训练日志，不能断言发生了某种实现错误或已识别因果根因。

可复算文件：先导复算.py；逐行依据：先导逐工况误差.csv；指标与输入绑定：先导指标.json；真实运行命令、Python 3.12.14、退出码 0 及输出：先导运行.log。另安排了不调用该复算脚本的只读独立核算，记录见 独立复核.md；该算术核对不等于正式 V2 全量独立复算。
