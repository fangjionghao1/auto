# 实验设计 P0：给定合成先导的全量复核

本文件在运行复算脚本前冻结；只复核既有输入，不模拟新预测或主实验。给定先导已经供设计使用，任何新方案都不得将其称为未接触保留测试。

| 问题 | 可证伪假设 | 方法机制 | 实验干预 | 主指标 | 对照 | 允许的结论 |

| 相同信息下预测增益 | 给定全量工况 MAE_proposed ≤ 0.9 × MAE_baseline | 当前未提供算法或生成机制 | 本次只比较固定的两列预测，不进行干预 | 按工况等权 MAE（kW） | baseline_kw | 先导样本内合同满足或失败；不能推出泛化或机制贡献 |

公式：e_im = prediction_im − actual_i；AE_im = |e_im|；MAE_m = (1/N)Σ_i AE_im。每个 case 当前恰好一行，工况等权与行等权在该文件中一致；后续若工况有多条时刻，先求每个工况 MAE 再跨工况等权。差值 Δ = MAE_proposed − MAE_baseline；比值 R = MAE_proposed / MAE_baseline；改善率 = 1 − R。若基线 MAE 为零，R 不定义，直接按主指标绝对值和合同判断，不能除零。

## 数据和复算规则

1. 输入固定为 pilot.csv 全部 20 行。验证列、唯一工况、有限数值和预测及负荷非负；原 CSV 不覆盖、不删行。
2. 逐工况保存有符号误差、绝对误差、误差差值及方法优劣；计算 Decimal 精确数值并保存 JSON 和 CSV。
3. 复算不用训练、调参或随机抽样；无随机种子。重复运行不是增加独立样本。
4. 列的 kW 单位来自字段名；100–195 kW 的实际负荷范围来自合成先导本身，不能充当工程额定功率或可行运行范围依据。
5. 没有时间、负荷对象、历史特征、天气、日历、组别来源和模型训练记录，无法认证时间泄漏、同信息公平性、代表性或样本独立性。不能把“没有相关列”判作这些项目通过。
6. 工况统计单位仅为给定 case。合成记录无概率抽样/随机生成证明，本次不报总体置信区间、不报显著性、不把残差样本方差当泛化不确定性。
7. MAE 是唯一合格判据；偏差、最大误差和逐工况计数只用于诊断，不能用于替换失败的主指标。
